# Benchly v2.15.0 — New look: "Precision" (redesign, Phase 1)

Benchly begins a phased redesign that makes the app **simpler by being smarter, not smaller** —
every feature stays. This first release lays the foundation: a new default design language.

## Precision
An editorial / instrument-panel look replaces the old soft-card default:
- **Hairline rules and a strict grid** instead of drop-shadows and rounded "bento" cards.
- **Squared corners**, a **cool blue-grey** neutral ramp, and **colour reserved for meaning**.
- **Pick your own accent** — **Iris** (default), **Coral**, **Amber** or **Teal** — from the
  Appearance menu. Remembered per user.

## Nothing lost
- **Graphite is still here, pixel-for-pixel** — one click away in the Appearance menu (or launch
  with `--theme graphite`). Frosted Glass and Chevron are unchanged.
- Every page, tool, table and filter is untouched; the number-key page shortcuts, Ctrl+K command
  palette, hover tooltips, and hide-until-elevated hardening all work exactly as before.
- The saved theme and accent now paint **instantly on launch with no flash**.

## What's next (the rest of the redesign)
A task-first **Home "Console"** that surfaces the few things worth a look, **grouped navigation**,
progressive-disclosure deep pages, a **bespoke icon set**, and a **smarter/faster PowerShell**
back end all follow in the v2.15.x line. Light mode is a later phase (Precision is dark-first for now).
